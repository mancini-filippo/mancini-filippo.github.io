# Filippo Mancini

Personal academic website, built with [al-folio](https://github.com/alshedivat/al-folio) and Jekyll. All site content is in English.

See [PUBLISHING.md](PUBLISHING.md) for the Italian guide to free GitHub Pages publication and maintenance, and [CONTENT_NOTES.md](CONTENT_NOTES.md) for editorial notes.

## Build

```sh
bundle install
bundle exec jekyll serve
```
